A travel poster for a place that does not exist, built for the make.fun
the-poster-for-a-place-that-i-2-20261121-0539 bounty: **LUMENARA**, the
floating isles where the sky swims with light — giant lantern jellyfish
drift over glass lagoons at dusk, under a low gold sun.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `entry.png` (the image, sitting next to it) to
`$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`). Deterministic: both runs
write the same bytes.

## The image

`entry.png` is 1024×1024, 206,777 bytes. It was drawn entirely with
Python/PIL as a flat vintage travel poster: indigo-to-peach dusk gradient,
three glowing sky-jellyfish, a low sun over a teal sea, a silhouetted isle
with spire trees and a lantern sailboat. LUMENARA is an invented name —
no real place, no quotes, no ratings.
